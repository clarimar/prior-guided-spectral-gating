# Revision R1 — Response to Reviewer #2 (Manuscript CHEMOLAB-D-26-00658R1)

This folder contains all materials produced during the first round of
peer review of the manuscript

> **Prior-Guided Spectral Gating for Interpretable Deep Learning in
> Near-Infrared Spectroscopy**

submitted to *Chemometrics and Intelligent Laboratory Systems*
(Elsevier). It exists to make the revision fully auditable: any reader
should be able to reproduce every numerical claim added to the
manuscript in this round.

## Context

Reviewer #2 raised one comment on the *Experiments* section:

> "Selecting the number of PLS components based on the lowest
> cross-validated RMSE may sometimes increase the risk of overfitting.
> Could the authors please clarify how this risk was controlled during
> the component-selection procedure?"

The concern is legitimate: the R1 submission selected `H = 10` on both
datasets using the argmin of the leave-one-out RMSECV, without a formal
safeguard against overfitting.

## Response

We adopted the **one-standard-error rule** of Hastie, Tibshirani and
Friedman (2009) as a pre-registered selection criterion, applied to the
leave-one-out cross-validation curve on the training set:

    H* = min { H : RMSECV(H) <= RMSECV(H_min) + SE(H_min) }

Applied to the identical training partitions used in the R1 submission,
the rule yields:

| Dataset  | n_train | H_min (argmin RMSECV) | RMSECV(H_min)      | SE     | Threshold | H* (one-SE) |
|----------|---------|-----------------------|--------------------|--------|-----------|-------------|
| Tecator  | 172     | 14                    | 0.2093             | 0.0269 | 0.2362    | **10**      |
| Gasoline | 48      | 6                     | 0.1250             | 0.0144 | 0.1393    | **5**       |

For Tecator, `H* = 10` coincides with the originally reported value —
nothing changes.

For Gasoline, `H* = 5` differs from the originally reported `H = 10`
(which was overly liberal). Applied to the identical train/test split,
the PLS Gasoline baseline improves from `R² = 0.941` (RMSE = 0.223) to
`R² = 0.975` (RMSE = 0.145).

None of the qualitative conclusions of the manuscript is affected. The
Gasoline predictive gap between the PGSG framework and PLS widens from
1.3% to 4.7%, requiring rewording of three paragraphs (Sections 6.2,
7 and 8) that discussed the original gap.

## Reproducing the analysis

The reproducible pipeline consumes the pickles generated by
`src/data/preprocessing_multi.py` in the root of the repository.

    # from repo root
    python src/data/preprocessing_multi.py --dataset tecator
    python src/data/preprocessing_multi.py --dataset gasoline

    # verify the R1 PLS baselines reproduce the values reported in the manuscript
    python scripts/baseline_pls.py                     # Tecator: R² = 0.9191
    python scripts/baseline_pls_multi.py --dataset gasoline   # Gasoline: R² = 0.9414

    # apply the one-standard-error rule and produce H* selections
    python revision_r1/one_se_analysis.py > revision_r1/one_se_output.txt

Expected result: exactly the H_min / H* / RMSECV values listed in the
table above.

`scripts/create_main_figures_600dpi.py` in the root of the repository
