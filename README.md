# Chemometric Prior-Guided Deep Learning for NIR Spectroscopy

**Status**: 🚧 Active Development  
**Target**: Analytica Chimica Acta / Chemometrics and Intelligent Lab Systems

## Quick Overview

Interpretable spectral band selection framework that bridges classical chemometrics and deep learning.

**Key Innovation**: Neural gates initialized with chemometric priors (ANOVA/VIP/RF) + KL regularization for interpretability.

**Validation**: 3 public NIR datasets (Tecator, Shootout 2002, Corn)
